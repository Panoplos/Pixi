# Demo recordings

The GIFs in the README are recorded from these tapes with [vhs](https://github.com/charmbracelet/vhs). Everything runs against a throwaway agent home under `/tmp/pixi-demos`, so your real `~/.pi` and projects stay untouched.

## Requirements

- `vhs`, `tmux`, and `pixi` / `pixi-rpc` on `PATH` (`~/.local/bin` works)
- Menlo, the font the tapes set
- `pixi-mask` on `PATH` for the masking demo, and an API key in `~/.pi/agent/auth.json` for the model the demos use (`demos/settings.json`)

## Record

```sh
bash demos/record.sh
```

That resets the throwaway home, records `prefix`, `rpc`, and `mask`, and copies the GIFs to `docs/images/{prompt-prefix,rpc-send,secret-masking}.gif`. To record one tape:

```sh
bash demos/setup.sh
cd demos && vhs prefix.tape
```

## What each tape shows

| Tape | File | Feature |
| --- | --- | --- |
| `prefix.tape` | `prompt-prefix.gif` | a project `promptPrefix` setting changes the input prefix after a relaunch |
| `rpc.tape` | `rpc-send.gif` | `pixi-rpc send` drives a running session from a second pane |
| `mask.tape` | `secret-masking.gif` | `key-guard.ts` masks secrets before they reach the model |

## Files

- `env.sh` — shared paths, sourced by the setup script and the tapes
- `setup.sh` — builds the throwaway home: copies `auth.json`, `demos/settings.json`, `key-guard.ts`, the lavender theme, and writes the `fake.env` and `prefix.json` fixtures
- `rpc-demo.sh` — tmux driver for the RPC demo: waits for the socket, types the `pixi-rpc send` command, holds the last frame
- `tmux.conf` — no status bar, extended keys on, `tmux-256color`

The `fake.env` used by the masking demo is generated by `setup.sh`; the keys in it are fabricated, not real credentials.
